# Major Project Frontend

This is a Vite React + TypeScript frontend scaffold integrated with Material UI, React Router and React Query. It includes pages and API client stubs wired to the backend's API surface under /api/v1.

Setup

1. cd frontend
2. npm install
3. npm run dev

Notes

- Update VITE_API_BASE in .env if your backend runs on a custom URL.
- The login page expects an /auth/login endpoint that returns { access_token }.
- This is a starting point with components, routing and API clients; expand pages and components to match product needs.
